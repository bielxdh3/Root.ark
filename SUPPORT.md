# Support

Root.ark is experimental self-hosted software under active development and does not provide a commercial support SLA.

## Bugs

Use the GitHub bug-report form. Include the Root.ark revision, operating system, affected component, reproduction steps, and sanitized evidence.

Do not post credentials, JWTs, cookies, encryption keys, databases, uploads, backups, audit logs, private paths, or other user data.

## Setup and usage

Start with:

- [README.md](README.md)
- [docs/development-setup.md](docs/development-setup.md)
- [BACKUP.md](BACKUP.md)
- [SYNC.md](SYNC.md)
- [WEBDAV.md](WEBDAV.md)
- [ENCRYPTION.md](ENCRYPTION.md)

If the documentation does not answer the problem, open an issue with the minimum safe information needed to reproduce it.

## Feature requests

Use the feature-request form and explain the problem first. Large features should follow the repository's plan-tree and issue workflow before implementation.

## Security

Do not report vulnerabilities in a public support issue. Follow [SECURITY.md](SECURITY.md).
